# Fireflies — privacy & support

The public page for the **Fireflies** iPhone app: its privacy policy and its
support contact. Apple requires a reachable privacy policy URL before an app can
be submitted, and this is it.

One self-contained HTML file plus the font it uses. No build step, no
dependencies, no tracking on the page itself.

Served at **https://sarah-soha.github.io/fireflies-app/**

The typeface is [Lora](https://github.com/cyrealtype/Lora-Cyrillic), the same
serif the app uses, under the SIL Open Font License — its licence travels with
it in `fonts/OFL.txt`.
